# 格式对照

本项目以指定的 2026 届软件工程 Word 模板为主要依据。学校《本科毕业论文撰写规范》第三部分允许学院根据学科特点制定具体要求，因而目录及摘要的学院专用要求按 Word 批注落实。原 Word 中的示例文本和提示与真实提交内容分开维护。

## 原稿内部差异的处理

| 差异 | 本项目采用方式 |
| --- | --- |
| 学校目录规范为小二标题、四号内容；学院 Word 批注为三号标题、小四内容 | 遵循指定学院 Word 的批注，与其实际目录字号一致 |
| 学校英文关键词使用逗号；学院 Word 的批注和范例使用分号 | 遵循指定学院 Word，使用分号 |
| Word 批注 7 与参考 PDF 的奇数页页眉均为“华东交通大学毕业设计”，学校通用规范另写“华东交通大学毕业论文” | PDF 沿用指定 Word 范本实际页眉；偶数页为姓名与题目提示，正式稿填入元数据 |
| Word 文献说明引用 GB7714-87；学校新规范引用 GB/T7714-2015 | 使用学校现行规范中明确指定的 2015 版；保留原稿七条文献作为著录范例 |
| 学校装订清单把致谢列在附录之后；学院 Word 目录把致谢列在参考文献之前 | 沿用指定 Word 的实际章节顺序 |
| 原中文摘要说二层架构，英文范文说三层架构 | 保留原稿中英文范文；作者完成论文时应按实际架构统一改写 |
| 原稿封面完成日期出现 2025 年，文件标注 2026 届 | 元数据默认 2026 年，具体日期由作者填写 |
| Word 以空段落和分节产生空白页，部分页面有批注框 | LaTeX 保留前置空白页及 guide 模式的可见提示，目录自动更新；`final` 模式隐藏提示 |

## 核验范围

`scripts/check_format.py` 同时检查 TeX 实际布局数值、最终日志和 PDF 的可测属性。所有检查项写入 `build/format-report.json`，包含 PDF 的 SHA-256，使报告与核验版本对应。摘要和目录使用参考范本的专用版心边界；字体的中文标点字面框含有可压缩空白，因此版心检查基于实际渲染墨迹，边缘取整容差 0.8 bp。单个灰度 128～179 的浅色抗锯齿像素不判为可见越界：参考与当前第 15 页右边缘均出现同一个灰度 178 的像素；两个以上低于 180 的像素或任何低于 128 的像素仍会触发检查。尺寸和字号容差保持 0.03 bp。固定断行产生的 underfull 提示写入报告，但不会将无溢出的松盒视为失败；当前数量见核验记录。

严格视觉对照另外检查完整页面的 RGB 像素是否相等，并输出逐页并排图和差异图。字体、文本和几何诊断只帮助定位差异，不替代逐像素结果。

随附范例通过 `assets/guide-layout.json` 保存从参考 PDF 测得的字符位置差和少量图形参数。`scripts/pdf_microtype.py` 在 XeLaTeX 输出上调整字距和基线、原有图片的变换矩阵，以及声明框和工资表的边线连接方式；文字仍使用 XeLaTeX 生成的字形，表格内容仍由 LaTeX 排版。封面文字框沿用 Word 的内部裁切边界和描边参数。

校准同时核对源文件哈希及原生 PDF 布局指纹。源文件改写后使用正常 LaTeX 排版；首次编译、改写内容和 `final` 模式均有回归覆盖。对已校准范例的行距检查使用参考 Word 中文摘要的 17 条固定基线及 0.03 bp 容差；正常 LaTeX 文档继续检查 19.5 bp 行距及原有 0.05 bp 容差。

编译和自动检查后必须逐页检查渲染图，确认封面填写位置、声明签名区、换行、图表线条和表格内容。模板的版式核验与完成论文的字数、研究内容、文献时效、引用真实性属于不同检查范围；真实论文还须依学院提交要求审核。
