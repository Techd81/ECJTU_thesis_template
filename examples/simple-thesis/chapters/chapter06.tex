\chapter{总结与展望}
\section{工作总结}
本文围绕校园自习室预约需求，实现了一个可重复运行的 Python 与 SQLite 业务原型。原型以关系表描述用户、座位和预约，使用左闭右开的时间区间判定冲突，在事务内完成预约检查与写入，并通过记录状态支持取消和资源释放。

实际执行的 \SampleTestCount{} 项功能用例全部通过。测试结果表明，正常预约、相邻时段、重叠拒绝、归属检查、取消后再次预约和日期隔离均符合所定义的业务规则。统计查询得到的有效预约数量与累计分钟数也与测试记录一致。原型代码、测试数据与运行说明共同构成了后续开发的可复现基础。

\section{后续工作}
后续开发可从三个方面展开。首先，接入校园统一身份认证，通过会话提供可信用户编号；其次，增加座位查询与预约交互页面，帮助学生直观选择日期和时段；最后，引入签到、超时释放与使用记录，完善预约和实际使用之间的关联。

随着用户规模扩大，还需针对多个数据库连接发起的预约请求开展竞争测试，明确锁等待与重试策略，并通过真实使用数据评估查询性能。上述工作可沿用现有业务接口，逐步扩展运行环境和验证范围。
